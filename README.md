# stepwise_identity
this is a repo to explain how identity works in our microservices environment

## Mini IdG

[src/IdentityServerHost](src/IdentityServerHost) is a mini Identity Gateway, built from
scratch in phases that mirror `Applications.IdentityGateway`'s real architecture.
Phase 1 (foundation) is done — see its [README](src/IdentityServerHost/README.md) for
what it is and how to run it.
